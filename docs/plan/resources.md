# Resources (checked September 2026)

## Core practice (free)
- SadServers: real broken Linux servers, closest to a live troubleshooting round. https://sadservers.com/scenarios (Pro is about $5 a month)
- iximiuz Labs: Linux, networking and Kubernetes playgrounds and challenges; generous free tier. https://labs.iximiuz.com
- Killercoda CKA scenarios: https://killercoda.com/cka. The CKA exam includes two killer.sh simulator sessions.

## CKA
- Piyush Sachdeva's CKA 2025 series: playlist https://www.youtube.com/playlist?list=PLl4APkPHzsUUOkOv3i62UidrLmSB8DcGC and repo https://github.com/piyushsachdeva/CKA-2024 (day folders under Resources/DayNN).
- Exam: list price about $395–445; 30–65% coupons are common, so India typically pays ₹12,000–22,000. Includes a free retake.
- Kubernetes the Hard Way: https://github.com/kelseyhightower/kubernetes-the-hard-way
- Gateway API migration guide: https://gateway-api.sigs.k8s.io/guides/getting-started/migrating-from-ingress/

## Linux depth
- Brendan Gregg: the 60-second checklist (https://www.brendangregg.com/Articles/Netflix_Linux_Perf_Analysis_60s.pdf), the USE method, perf, flame graphs, the bpftrace introduction. Book: Systems Performance.
- Julia Evans' strace zine (free), Liz Rice's Containers From Scratch talk, man7.org man pages, kernel docs on cgroup v2 and PSI.

## Observability and SRE
- Google SRE book and Workbook, free at https://sre.google; read "Alerting on SLOs" for burn rates.
- PromLabs (Julius Volz) on YouTube, plus paid self-paced courses. Grafana Cloud's free tier for practice. Loki label best practices in the Grafana docs.

## AWS
- Adrian Cantrill's SAA-C03 course ($40, lifetime access, 14-day refund). Andrew Brown's free SAA-C03 course on freeCodeCamp (about 50 h).
- EKS Workshop v2: https://github.com/aws-samples/eks-workshop-v2
- SAA-C03 exam: $150, about ₹15,135 with GST from India.

## Distributed systems and design
- Designing Data-Intensive Applications, 2nd edition (O'Reilly, March 2026). Martin Kleppmann's Cambridge lectures on YouTube (free). The SRE Workbook's non-abstract large system design chapter.

## Interview prep
- Question banks: https://github.com/bregman-arie/devops-exercises and https://github.com/mxssl/sre-interview-prep-guide
- Human mocks: Topmate DevOps/SRE mentors (about ₹199–1,299 an hour), Prepfully ($89–399), interviewing.io ($179–339).
- Voice interview practice: the Claude app's voice mode on the phone. Terminal rounds: /interview here.
